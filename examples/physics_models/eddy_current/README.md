# Eddy currents

Depth of reach for eddy-current testing, induction heating, plate losses and magnetic braking.

* **Physics:** `physics_kit.eddy`, which covers skin depth, the exact 1-D plate solution and Reitz's moving-magnet forces.
* **Data:** measured conductivities (material plus %IACS columns) win over the table. Phase-lag readings on a reference block with known flaw depths calibrate the conductivity (`sample_data/`).

The sample data is made up to show the format. Replace the link with your own folder, a Ledger or a Connections graph in the Model view.

Run the tests with **Test** in the Build tab. Open the **Model** view to set the inputs and see the design sheet.
