# Council — runtime dependencies

# Install with:  pip install -r requirements.txt

# IMPORTANT: this file is the BARE-MINIMUM pip-only install.
# For a real working setup — especially if you have an NVIDIA GPU —
# follow installs.txt instead. installs.txt sets up a conda env
# with the right CUDA wheels for torch + llama-cpp-python, pins
# numpy / pandas / h5py through conda-forge to avoid ABI breaks
# with dream3dnx, and matches the install order pip alone can't
# guarantee.

# dream3dnx moved to 3.12-only builds and dragged the whole stack
# forward.)
