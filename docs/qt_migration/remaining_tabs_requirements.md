# The eight remaining tabs — what the Qt port must do

Produced 2026-09-18 by a 16-agent reconnaissance: one reader per tab, then an
adversarial verifier per map that re-checked every API signature against the
source and tried to REFUTE every claimed defect.

**299 API claims were checked and 18 were wrong.** Every one of the eight maps
came back NEEDS_CORRECTION. That is the reason the verify pass exists: an
assumed signature has broken this port seven times, and a map nobody checked
would have carried eighteen more into the implementation.

46 defects survived refutation; 26 were refuted and are not listed. Most of the
survivors are SILENT — the user gets a result, just the wrong one.

## agents

A read-only availability board for eight optional agent subsystems, three session toggles that steer the council turn, a vault RAG re-index button, an agent event log, and two whole sub-UIs embedded from other modules — the Sage tuning panel and the Vault Agent ReAct task runner.

*NEEDS_CORRECTION* — 58 API claims checked, 3 wrong.

> THREE MATERIAL OMISSIONS the map should have carried, in descending order of port impact:
> 
> 1. tkinter-absent builds crash this tab with AttributeError. BOTH panel classes are defined inside `if _TK_OK:` guards - sage_agent.py:359-369 and vault_agent.py:557-567 - where the tkinter import sits in try/except. But _SAGE_OK and _VAULT_AGENT_OK (engine 84-88, 78-82) are set purely by whether `import sage_agent` / `import vault_agent` succeeds, which it does with or without tkinter. So on a PySide-only build with no Tk, _SAGE_OK is True, `sa.SageTuningPanel` does not exist, and engine:10955 raises AttributeError - and the `elif not _SAGE_OK` fallback at 10961 cannot fire. Same at 10979 for va.VaultAgentPanel. This is exactly the end-state the Qt port is heading toward, and the map's binary `toolkit_free: false` hides it.
> 
> 2. Related: `toolkit_free: false` is too coarse for both modules.
